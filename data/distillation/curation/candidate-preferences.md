### SpaceXAI / frontier FT target band (±10% of median)

User rule: **infer from SpaceXAI median, accept 10% below – 10% above.**

| Component | Median anchor | Target band (−10% … +10%) | Use |
|-----------|---------------|---------------------------|-----|
| **Total comp (TC)** | $640K | **$576K – $704K** /yr | Primary SpaceXAI-tier / US frontier FT mutual-fit band |

**Scoring:**

- SpaceXAI / Elon multi-planetary FT: offer inside **TC $576K–$704K** (or base ≥ ~$216K with strong equity path) → strong `role_to_candidate` on money.
- Below −10% TC without exceptional equity narrative → **pause / negotiate**, not auto-reject if mission is SpaceXAI.
- Far below base band with weak equity → treat as underpriced unless user overrides.

**Non-US / Nordics FT:** Do **not** apply the $576K–$704K TC band blindly (HCOL US frontier). Score via **net savings floor** below and local market reasonableness; SpaceXAI-tier TC is the US/wishlist anchor.

## Dual-fit scoring hints (for future analyze schema)

When scoring `role_to_candidate` / deal-breakers:

1. **DEI-primary culture / geo** → deal-breaker or hard pause if clearly evidenced.  
2. **Mode mismatch:** e.g. pure onsite mid-size slow niche without hybrid → concern; SpaceXAI onsite → fine.  
3. **JP/CH/SG/PL without HW+SW high-potential AI/robotics/med-tech** → soft reject.  
4. **London unsafe/insecure framing** → soft reject.  
5. **Collab-only while FT SpaceXAI not secured** → lower priority (discovery weight), not always ignore.  
6. **EM-first with no IC path** → mild concern (IC start preferred).  
7. **Weekend-hostile / always-on culture** → role concern (family weekends).  
8. **US sponsorship available + SpaceXAI / strong trajectory** → boost `role_to_candidate`.  
9. **Equity present** → positive; do not replace SpaceXAI cash band entirely.  
10. **Physical-world ML / world models / multi-planetary Elon-adjacent** → strong mission boost.  
11. **SpaceXAI-tier FT money:** TC in **$576K–$704K** (or base ≥ ~$216K + strong equity) → money pass; far below → pause/negotiate.  
12. **Decent/debt FT:** estimated **monthly** post-tax post-living savings **$5k–$10k USD** → pass; below $5k → weak.  
13. **Contract:** rate &lt; $100/hr → reject; $100–$124 → acceptable floor; **$125–$150** target; $150+ stretch for ML/agent scarcity.
