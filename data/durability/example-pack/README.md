Copy `universe.json` (and optionally a `places.json`) into `~/.config/collab-finder/packs/`. Then Settings → Rank packs, or Mission Next 10.

Same `id` as an operator firm replaces that row.

**Maintained list:** edit `universe.v1.json` in git (or your pack overlay) — see [`../README.md`](../README.md) and [`../../mission-firms/FIRM-LIST.md`](../../mission-firms/FIRM-LIST.md).

`mission-firms.json` can attach `score_bonus` / `score_reason` to registry firms (e.g. `volvo_cars` Stockholm watch) without adding a duplicate board — bonus-only rows are merged by `id`.
