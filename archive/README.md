# archive/

Non-functional or stale repo material kept for history. **Do not** move runtime source, CI scripts, or operator data here.

| Path | Why archived |
|------|----------------|
| `reports/` | Planning / UX / tech-debt write-ups from earlier passes — superseded by `docs/` and shipped UI where landed |

When in doubt during cleanup: **archive over delete**. Update any doc links that pointed at the old path.
